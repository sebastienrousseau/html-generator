## Highlights ⭐️

* **Hardened HTML and CSS sanitization (`ammonia 4.2.4`)**: Upgrades `ammonia` to `4.2.4` to remediate `RUSTSEC-2026-0373` (case-insensitive CSS `url()` matching), `RUSTSEC-2021-0157` (CSS `url("")` escaping), and `RUSTSEC-2021-0158` (SVG animation element `href` stripping).
* **Ecosystem and dependency updates (`noyalib 0.0.58`, `comrak 0.56.0`)**: Advances `noyalib` to `=0.0.58`, `comrak` to `0.56.0`, `tokio` to `1.54.1`, `serde_json` to `1.0.154`, `toml` to `1.1.8`, and `pulldown-cmark` to `0.13.5`, with `cargo-vet` audits recorded in `supply-chain/audits.toml`.
* **Rust 1.89.0 MSRV alignment**: Raises `rust-version` to `1.89.0` across `Cargo.toml`, `README.md`, `CONTRIBUTING.md`, and issue/PR templates, enforced by `scripts/verify-release-versions.sh`.
