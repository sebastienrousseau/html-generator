## Highlights ⭐️

* **Hostile YAML front matter is refused**: `noyalib` moves to 0.0.56 for RUSTSEC-2026-0333. A few hundred bytes of front matter built from nested aliases used to expand into megabytes of JSON; `extract_front_matter_data` now returns an error instead.
* **No crash on long runs of email addresses**: `mdx-gen` moves to 0.0.6, which requires comrak 0.55 for GHSA-xg9p-p4jc-c46g. With the autolink extension the native renderer uses, about 2,000 bare email addresses in one paragraph overflowed a 512 KiB worker-thread stack and aborted the process; `tests/autolink_stack.rs` now renders 3,000 of them on such a thread.
* **The declared Rust floor is the real one**: `rust-version` is 1.88.0, the version the dependency graph already needed (it said 1.80.0). A new CI job builds the library on that toolchain so the two cannot drift apart again.
* **Dependencies up to date**: the `ammonia` 4.1.5 security backport, `comrak` 0.55, the patch releases of `indexmap`, `thiserror`, `toml` and `test-case`, and current GitHub Actions pins.
